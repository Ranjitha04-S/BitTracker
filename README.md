# BitTrack

**BitTrack** is a user-centric Bitcoin utility application that provides essential tools to support Bitcoin users in managing their assets and transactions efficiently. The application features:

- **Live Bitcoin Price Tracker:** Displays real-time Bitcoin price data using the CoinGecko API.
- **Bitcoin ATM Locator:** Enables users to locate nearby Bitcoin ATMs utilizing CoinATMRadar and Google Maps services.
- **Bitcoin Tax Calculator:** Allows users to estimate potential tax obligations based on transaction amounts and general location input.

Each component has been thoughtfully designed for clarity, responsiveness, and ease of use across a wide range of devices.

## Technologies Used

- **Framework:** React (with Vite for rapid development and optimized performance)
- **Styling:** Tailwind CSS
- **Languages:** HTML, CSS, JavaScript

### APIs Integrated

- [CoinGecko API](https://www.coingecko.com/en/api): For live Bitcoin pricing.
- [CoinATMRadar API](https://coinatmradar.com): For Bitcoin ATM location data.
- [Google Maps API](https://developers.google.com/maps): For geolocation and map rendering.

## Key Features

- Up-to-date Bitcoin price visualization
- Interactive map for locating Bitcoin ATMs based on the user's location
- Estimation of cryptocurrency tax liabilities based on user input
